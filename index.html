Backup — full rebuild

One .sql file containing the complete schema plus every row, in dependency order. Run it against any empty Postgres database — Supabase or otherwise — and everything comes back. This is the real insurance.

For Excel

Or every table exactly as stored — one file each, downloaded in sequence. Your browser may ask permission for multiple downloads.

Recommended routine
Keep three things together wherever you store backups: the .sql file (schema + data), PROJECT_HANDOFF.md (the design reasoning — why envelopes span accounts, why labels don’t decide envelopes, what’s still unbuilt), and a copy of index.html (the entire app; no build step, no dependencies). Those three rebuild everything from nothing, with or without Supabase, with or without Claude.

Edits save when you leave a field. Changing an envelope’s owner or category only changes how it’s grouped — no money moves.
